# AI PM Harness

A bring-your-own-key (BYOK) workspace for Product Managers to run multi-agent research-to-PRD pipelines with end-to-end customer evidence traceability.

Every PRD requirement generated by the harness is strictly grounded and traceable back to a verbatim customer transcript, ticket, or analytics metric:

$$\text{Customer statement} \longrightarrow \text{Problem} \longrightarrow \text{Supporting evidence} \longrightarrow \text{Opportunity} \longrightarrow \text{Proposed feature} \longrightarrow \text{Business impact} \longrightarrow \text{Priority} \longrightarrow \text{PRD requirement}$$

---

## Key Features

- **Multi-Provider BYOK (Bring Your Own Key):** Supports Anthropic (Claude), OpenAI (ChatGPT), and Google Gemini via direct, secure browser requests.
- **7-Stage PM Pipeline:**
  1. **Research Agents:** Parallel extraction across customer interviews, support tickets, analytics CSVs, competitor intel, and business OKRs.
  2. **Cross-Source Insights:** Detects patterns and deliberate contradictions between customer segments.
  3. **Problem Formulation:** Classifies severity, personas, and computes evidence confidence (*anecdotal*, *corroborated*, *triangulated*).
  4. **Scoring & Prioritization:** Automated RICE, ICE, or WSJF scoring with manual PM overrides.
  5. **Product Requirements Document (PRD):** Functional specs, personas, and testable Given/When/Then acceptance criteria.
  6. **Release Roadmap:** Automatic horizon allocation (*Now*, *Next*, *Later*) with cyclic dependency prevention.
  7. **Executive Review & Audit:** Rubric critique with automatic code overrides if goals are unlinked or quotes are unverified.
- **Evidence Explorer & Reverse Trace:** Interactive horizontal flow cards linking every requirement to verbatim source chunks.
- **Grounded RAG Chat:** Multi-turn conversation with cited chunk chips (`[D1-C2]`), search scope filtering, and optional real-time web search grounding.
- **Diagnostics & Self-Tests:** Built-in automated test suite running 18 pure-logic benchmarks (T01–T18) with zero API keys required.

---

## Security & Secrets Hygiene

- **Client-Side Only:** No backend server or proxy. All data is processed client-side in the browser and stored locally in IndexedDB / localStorage.
- **No Pre-Provisioned Keys:** The application never reads or bundles pre-set environment variables. Keys are entered by the user in Settings and kept in `sessionStorage` (or optionally `localStorage` if "Remember on this device" is checked).
- **Redaction:** Keys are masked as `••••a1b2` in the UI and stripped from exports, error logs, and URL fragments.

## Getting Started

### Local Development

1. Clone repository and install dependencies:
   ```bash
   npm install
   ```
2. Start the local development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000` in your browser.

### Building for Production

Compile the static single-page app:
```bash
npm run build
```
The output will be placed in the `dist/` directory.

---

## Deployment to Render (Static Site)

1. Push your repository to GitHub.
2. In Render, select **New -> Static Site** (or use Blueprint with `render.yaml`).
3. Set:
   - **Build Command:** `npm install && npm run build`
   - **Publish Directory:** `dist`
4. Deploy. No environment variables are required!

---

## Self-Review Verification

Visit `#/diagnostics` in your browser and click **Run All Tests** to verify all 18 pure-logic unit tests (T01 to T18) pass without requiring an active API key.
